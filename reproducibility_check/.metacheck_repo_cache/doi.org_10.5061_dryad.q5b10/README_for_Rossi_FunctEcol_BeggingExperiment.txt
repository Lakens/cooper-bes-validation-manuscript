Rossi et al., Functional Ecology, "Begging blue tit nestlings discriminate between the odour of familiar and unfamiliar conspecifics".

Bielefeld, 4 April 2017

Description of data file.

(1) File name: Rossi_FunctEcol_BeggingExperiment.csv

This data file was used to analyse the likelihood, duration and intensity of nestling begging responses to familiar versus unfamiliar odour stimuli, while controlling for several additional predictor variables.

Column labels:
- ObsNr -> Arbitrary observation number.
- BroodID -> Brood identity, given by nestbox number.
- ChickID -> Nestling identity, given by an arbitrary number.
- NailCode -> Code indicating the combination of nail clips given to nestlings to identify them within their brood. Nail clips are applied at 4 days of age (day 0 = day of hatching of the first nestling of the brood) to mark them before ringing them from day 7 onward.
- BSManip -> Brood size manipulation category; "1_U": unmanipulated, "2_C": control, "3_R": reduced.
- BS_BeforeManip -> Brood size before manipulation.
- BS_AfterManip -> Brood size after manipulation.
- OdourDonorNest -> Nestbox number of the nestlings serving as odour donor.
- F_U -> Variable indicating whether the odour stimulus was familiar ("F") or unfamiliar ("U").
- FD -> Variable indicating the duration of food deprivation; "1": 30min, "2": 90min, "3": 150min; treated as a factor (with 3 levels) in the analyses.
- Seq -> Stimulus order; treated as a factor (with 2 levels) in the analyses.
- BegResponse -> Variable indicating whether nestlings responded to the begging stimulus or not; "1": response, "0": NO response.
- BegDuration -> Duration of begging response (in sec).
- BegScore -> Begging intensity score.
- ChickMassAtStart -> Nestling mass at the start of the odour discrimination test trials. This variable was used as a covariate in the analyses of the begging responses.
- ChickMassAfterFeed -> Nestling mass after feeding the nestlings to satiation after finishing the olfcatory discrimination test trials before returning them to their nest.
