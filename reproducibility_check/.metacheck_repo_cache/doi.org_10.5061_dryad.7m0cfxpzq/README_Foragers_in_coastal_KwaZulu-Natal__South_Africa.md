# Title of Dataset: Foragers in coastal KwaZulu-Natal, South Africa:
---

These data were collected by the author between October and November 2018. Methods included semi-structured interviews facilitated by an interpreter of isiZulu and isiXhosa and recorded with respondents' consent as audio files. Responses were anonymised, transcribed, and analysed using an inductive approach and thematic coding.


## Description of the Data and file structure

Blank cells indicate that questions were either not asked or answered. Questions can be found in Supplementary Materials of the related published manuscript.
