DATA-SPECIFIC INFORMATION FOR analysis.csv:

In this dataset there are listed all the environmental variables used for the paper, for all the statistical analysis performed and for all the graphs created

1. Number of variables: 18

2. Number of rows (including titles): 91

3. Variable List:
  1.site: site number (from 1 to 8)	
  2.name: name of the site
  3.area: is the area of sampling, "upstream" or "downstream" of the input of treated sewage in the river sampled
  4.pH: ph values
  5.O2: dissolved oxygen values. Unit: (mg/L)
  6.Temp: temperature measured in the rivers. Unit: Celsius
  7.TDS: Total Dissolved Solids measured. TDS are the organic and inorganic substances such as minerals, salts, metals, cations, or anions dissolved in water. Unit: (mg/L)
  8.Conductivity: To determine the amount of dissolved ions present in a sample. Unit: (µs/cm)
  9,10,11,12,13,14,15.:Fluoride, Chloride, Nitrite, Bromide, Nitrate, Phosphate, Sulfate: Nutrients and elements dissolved in water. Unit: (mg/L)
  16.TOC: Total Organic Carbon.  TOCis a measure of the total amount of carbon in organic compounds in pure water and aqueous systems. Unit: (mg/L)
  17.fungus	: number of fungus filaments in 20mL of water sample collected upstream and downstream in rivers, from the treated sewage outlet
  18. month : month of sampling (June, August, October, and November 2021)


CODE/SOFTWARE:

R studio has been used to make all the statistical analysis and graphs. 

Filament numbers between upstream, downstream, and effluent areas were analyzed using a linear mixed-effect model. Sampling month and site: explanatory variables, river: random effect. Data were log-transformed. Post-hoc tests(glht function in the "multcomp" package).

For each sampling month: PERMANOVA to test chemical and physical differences between areas, using the "adonis" function in the vegan package. SIMPER identified influential parameters. Regression analysis tested if these parameters affected downstream sewage fungus abundance, using log-transformed data.

Physical and chemical dissimilarity between upstream and downstream areas was shown using NMDS ordination on a Bray-Curtis distance matrix. Plots were created using ggplot2.
